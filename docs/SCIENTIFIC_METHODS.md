# 科学方法与公式出处

> 每个分析模块的公式、约定与适用条件。页码为论文 PDF 中印刷页码。
> 陈 = 陈哲琪《多尺度结构设计增强弹性体力学性能》(2024)；刘 = 刘博涵《可控相分离构建新型光学功能与超韧软材料》(2026)。
> 本文件只陈述论文中的方法定义，不包含任何从论文图表中读取的数值。

## 0. 单位约定

计算引擎内部一律 SI：力 N、长度 m、应力 Pa、应变能密度 J/m³（= Pa）、能量释放率/界面韧性 J/m²（= N/m）、时间 s、温度 K。展示层换算为 MPa、kJ/m²、°C 等。单位由 Pint 处理并做维度校验。

## 1. 单轴拉伸（SPEC §4.1）

| 量 | 定义 | 出处 |
|---|---|---|
| 拉伸比 | λ = L/L0 = 1 + Δl/L0，L0 = 夹具间距（标距） | 陈 p.43、p.77–78（夹具间距 20 mm 作初始长度）；刘 p.77（标距 20 mm） |
| 工程应变 | ε = λ − 1 | — |
| 名义应力 | σ_nom = F/A0，A0 = 初始宽 × 初始厚 | — |
| 真实应力 | σ_true ≈ λ σ_nom（不可压缩 + 均匀变形近似） | SPEC §4.1 |
| 应变能密度 | W(λ) = ∫₁^λ σ_nom dλ'（参考体积） | 陈 式 2-71（p.34）；陈 p.78 “应力-拉伸曲线和坐标轴围成的面积计算断裂功” |
| 断裂功 | W_f = W(λ_break) | 同上 |
| 初始模量 | 名义应力–拉伸比曲线初始段线性拟合斜率；拟合区间可配置 | 陈 p.78 “应力-拉伸曲线的初始斜率”；刘 p.77：弹性体取初始 1.05 拉伸比范围，塑料取 1.02 |
| 微分模量 | dσ_nom/dλ（数值微分，需平滑选项并记录参数） | — |

注意：
- 模量拟合区间不强制统一；结果必须附拟合区间、R²、残差、点数。
- 不得对 σ_true 积分并称为参考体积应变能密度。
- 应变率约定：陈第 3 章 1 min⁻¹，第 5 章 0.05 s⁻¹；刘第 5 章 0.5 s⁻¹（原文如此）。不同应变率的数据比较时需提示。

## 2. 循环拉伸（SPEC §4.2）

- W_loading = ∫ σ_nom dλ（加载段，λ 递增），W_unloading = ∫ σ_nom dλ（卸载段，按 λ 递增方向积分取正值），W_hys = W_loading − W_unloading。
- 循环闭合时 W_diss = ∮ σ dλ = W_hys。若卸载终点的 λ 与加载起点不一致（残余应变）或应力未回零，报告为“未闭合循环”，W_hys 仍按定义计算，但不解释为完整热耗散。
- 残余应变：卸载段应力降至设定阈值（默认 0 或用户给定力阈值）时的 λ − 1。

## 3. 纯剪切断裂韧性（SPEC §4.3）

- 几何：w0 ≫ h0 ≫ t0，宽度方向由刚性夹具固定（陈 p.33）。陈：60 mm × 10 mm（可拉伸部分），预切裂纹 15 mm（p.78）；刘：50 mm × 10 mm，预切裂纹 20 mm（p.77）。
- 两个尺寸相同的样品：无裂纹样品单调拉伸得 W(λ)；有裂纹样品单调拉伸得临界拉伸比 λc = hc/h0。
- G_c = H0 · W(λc) = H0 ∫₁^{λc} σ dλ（陈 式 2-71，p.34；陈 p.78；刘 p.77）。H0 = 未变形可拉伸高度。
- λc 定义：陈 “裂纹开始发生稳态扩展”（p.34）；刘 “裂纹恰好开始增长”（p.77）。两种定义需记录在结果的 `conventions` 中，不直接混比。
- 适用条件：小尺度非弹性（h0 ≫ 非弹性区稳态尺寸 Rp ~ G/W_f，陈 p.32–33）。由 Gc = H0·W(λc) 得 Rp/H0 ≈ W(λc)/W_f（≤ 1），结果中总是输出该比值；因 Rp ~ G/W_f 只是量级关系，仅在比值 > 0.5 时告警（`PROCESS_ZONE_WARN_RATIO`，本项目约定，非论文给出）。
- 其他告警（本项目约定）：w0/H0 < 4；t0 > 0.2·H0；c0 ≤ H0（陈 p.34 要求 c0 > h0）；c0 > 0.5·w0；λc ≥ 0.95·λ_break（无裂纹）；用户提供的滞后比 > 0.2（黏弹性）。

## 4. 循环纯剪切疲劳（SPEC §4.4）

- 每个拉伸幅度 λ 对应一个能量释放率幅度 G = H0 · W(λ)，W(λ) 取无裂纹样品循环至稳态后的加载曲线：陈 1000 次（p.78），刘 500 次（p.77）。
- 两篇论文的循环均以 λ 幅度描述，W(λ) 从 λ=1 积分（即最小拉伸比为 1，相当于 G_max = ΔG）。软件仍强制记录 λ_min、λ_max、载荷比与 G 约定（`G_max` / `delta_G`），约定不同的数据不得合并拟合。
- dc/dN = Δc/ΔN（陈 p.78 每个幅度 50,000 次后测 Δc；刘 p.77 至少 50,000 次）。陈还在测试前对含裂纹样品预循环约 5000 次以进入稳态（p.78）。
- 检测限：dc/dN_min = 位置分辨率 / 观测间隔循环数；刘 p.77：分辨率 ≈ 20 μm、50,000 次 → ≈ 0.4 nm/cycle；陈 p.79 同为 0.4 nm/cycle。低于检测限 → `below_detection_limit`（删失），不填 0、不进入普通线性拟合。
- 疲劳阈值 G_th：裂纹在循环加载下不扩展的 G 阈值（陈 p.35）。软件提供两种方法并分别标注：(a) 指定区间内 dc/dN–G 线性外推至 dc/dN = 0（输出参数、标准误差、bootstrap 置信区间、外推距离）；(b) 由“扩展的最低 G”与“未检出的最高 G”给出实验区间/下界。数据不足或不可辨识时拒绝给出数值。
- 有限循环未观察到扩展不等于不会疲劳——报告措辞固定为“在 N 次循环、检测限 X 下未检出扩展”。

## 5. DMA（SPEC §4.5，Should）

- 陈 p.43：拉伸模式，1 Hz，振幅 15 μm，−70 → 100 °C，3 °C/min；刘 p.76：变温，3 °C/min，振幅 20 μm，1 Hz。
- 陈 p.70 表注：Tg 取 1 Hz 温度扫描中 tan δ 峰对应温度；tan δ 由损耗模量除以储能模量计算。
- 实现（`polymech_mechanics.dma`）：
  - tan δ = E″/E′；三列只给两列时由此式求第三列（来源写入结果）。三列都给时检查 tan δ 与 E″/E′ 的中位相对偏差，> 5% 告警（常见原因：E 与 G 混用、列来自不同测试）。
  - 频率列含多个值时按频率分组（相对差 ≤ 1% 视为同一频率），每个频率单独识别 Tg，不合并；温度变化 < 2 K 且频率变化时为等温频率扫描，不报告 Tg。
  - Tg 候选按定义分别给出：**tan δ 峰**、**E″ 峰**（线性坐标，峰显著度 ≥ 曲线范围 10%，峰位用峰点及相邻两点的抛物线顶点插值）、**E′ 下降起始**（log₁₀E′ 中玻璃态基线〔默认最低 10% 温度范围〕的线性拟合与最陡下降点切线的交点，参考 ASTM E1640；下降不足 0.3 个数量级或交点不在基线与拐点之间时不报告）。
  - 峰只在测量范围内识别，不外推。次峰显著度 ≥ 主峰 50% 时判为多峰：列出所有峰，不自动选定、不写入材料性能，结果为临时状态；用户可限定 Tg 搜索温度区间后重新计算。
  - 异常点：对 log₁₀E′、log₁₀E″ 与测得的 tan δ，取与 7 点滑动中位数的残差，噪声尺度用二阶差分的 MAD 估计（滑动中位数在单调转变段残差为 0，会低估噪声）；|z| > 6 且相邻点 |z| < 3 的孤立点标为异常，在图中以空心点标出，不参与 Tg 识别，原始数据不修改。
  - 参考温度（默认 25 °C）下的 E′、E″、tan δ 线性插值报告（陈 p.70 表中 tan δ 取 25 °C 值），超出测量范围不报告。
  - 形变模式（拉伸 E / 剪切 G）由用户在参数中指定，只用于标注与比较分组。
- 多样品比较：Tg 按（定义、频率、形变模式）分组列出与统计，组间不比较。

## 6. 剥离（SPEC §4.6，Should）

- T 型剥离（陈 p.79）：粘接韧性 = 2 × 平台力 / 样品宽度 w。
- 裤型剥离（刘 p.78）：界面韧性 = 2 × 平台稳定力 / 样品**厚度** t。
- 两者分母不同（宽度 vs 厚度），对应不同的裂纹扩展面积定义；软件要求用户显式选择模型并确认尺寸，不按“剥离”名称自动套用。

## 7. 可比性检查（SPEC §7.5，Should）

实现：`polymech_database.comparability`（规则，确定性）。两条数值逐项检查，每项给出等级，总结论取最差一项：不建议直接比较 > 信息不足 > 有条件比较 > 可直接比较。

| 检查项 | 规则 |
|---|---|
| 指标类型 | 不同指标 → 不建议；断裂拉伸比 ↔ 断裂伸长率 → 有条件（λ = 1 + ε）；真实 ↔ 名义断裂应力 → 不建议 |
| 实验类型 | 不同 → 不建议；缺失 → 信息不足 |
| 数值形式 | 只有上/下界、原文约值 → 有条件 |
| 温度 | DMA 状态量（E′、E″、tan δ）：缺失 → 信息不足，相差 > 1 K → 不建议；其他：缺失 → 有条件（按室温比较需确认），相差 > 5 K 有条件、> 20 K 不建议 |
| 频率 / 形变模式 | DMA：缺失 → 信息不足；Tg 频率不同 → 有条件，状态量频率不同 → 不建议；拉伸与剪切 → 不建议 |
| Tg 定义 | 不同 → 不建议；缺失 → 信息不足 |
| 加载速度 | 单轴与韧性：速率比 > 3 有条件，> 30 不建议；缺失 → 有条件 |
| 应力定义 | 模量：真实/名义不同 → 有条件（小应变初始斜率接近）；强度：不同 → 不建议；未说明 → 有条件 |
| 断裂韧性 | 方法（纯剪切 / 阻力曲线）不同 → 不建议；λc 定义不同 → 有条件；H0 不同 → 有条件（过程区尺寸效应） |
| 疲劳阈值 | 判定方法（线性外推 / 裂纹止裂 / 实验区间）不同 → 不建议；G 定义表述不同、稳态预循环次数不同、检测限不同 → 有条件 |
| 循环指标 | 最大拉伸比不同 → 不建议；恢复时间不同 → 有条件 |
| 界面韧性 | T 型剥离与裤型撕裂 → 不建议 |

本软件的分析结果按引擎定义补全：应力为名义应力，断裂韧性方法为纯剪切。阈值（5 K、20 K、3 倍、30 倍、1%、5%）是本项目约定（`docs/DECISIONS.md`）。
