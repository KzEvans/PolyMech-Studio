# 文献材料数据库（SPEC §7.3）

## 1. 规则

- 只登记原文**明确印出**的数值，提取方式为“文献报告值”（`reported`），并附原文写法（`reported_text`）、印刷页码、图号/表号。
- 从插图读数的值必须标为“图形数字化估计值”（`digitized`）并注明图号。目前**没有**登记任何数字化值。
- 缺失的指标不登记（不填空、不估算、不换算出原文没有的量）。原文写作“约/~”的记为约值（`approximate`），“以上/超过/>”记为下界。
- 数值按原文单位写入数据文件，导入时换算为 SI。原文是伸长率（%）就登记为“断裂伸长率”，不改写为拉伸比；“断裂真实应力”与名义“断裂应力”分开。
- 同一材料同一指标在原文不同页给出不同数值时，**分别登记**并在备注中互相指明，不取平均、不择一。
- 只登记论文作者本人的测量结果。论文表格中引用其他文献的列（例如陈 2024 表 4-2 中 [57]–[60] 四列）属于二次引用，不登记。

## 2. 数据文件与导入

- 数据：`literature/theses_chen2024_liu2026.json`（格式 `polymech-literature/1`，说明见 `packages/database/src/polymech_database/literature.py`）。
- 导入：`make literature`（写入 `POLYMECH_DATA_DIR` 或应用默认数据目录），或在“材料数据库”页点“导入文献记录…”，或 `POST /api/literature/import`。
- 记录以“引用身份”（来源、材料、指标、页码、图表号、原文写法）识别：重复导入时未变化的跳过，内容有更正的原地更新。
- 为可比性检查补充的机器可读条件代码：`method`、`lambda_c_definition`（陈 2024 为 `rupture`：拉伸至断裂得到 λc；刘 2026 为 `crack_onset`：裂纹恰好开始增长）、`stress_basis`、`steady_state_cycles`；原文表述保留在 `*_note` 字段。
- 导入时整份文件先校验，任何一条不合格则整份拒绝（HTTP 422，指出第几条、原因）。重复导入是幂等的（按记录内容哈希跳过已有记录）。
- 文献材料名不能与实验材料重名，避免两类数据混在同一材料下。
- 不联网抓取任何数据库；扩展方式是按同一格式整理新的 JSON 文件。

## 3. 已登记记录

两篇学位论文的文献报告值记录（42 条，11 种材料）只保存在作者本地，公开仓库不包含该数据文件。导入格式见 `packages/database/src/polymech_database/literature.py`，可按同一格式整理自己的文献记录后导入。
