# 使用说明

> 软件内有更详细的版本：侧边栏“使用说明”（含公式、数据格式与常见问题，可搜索）。

## 0. 安装桌面版（macOS）

打开 `PolyMech Studio_0.1.0_aarch64.dmg`，把 App 拖到“应用程序”。App 未经 Apple 公证，第一次打开时请在 Finder 中右键 →“打开”。第一次启动需要约一分钟建立字体缓存，之后几秒内打开。数据保存在 `~/Library/Application Support/PolyMechStudio`（菜单“文件 → 在 Finder 中显示数据文件夹”）；下载的文件保存到“下载”文件夹。

## 1. 一次单轴拉伸分析

1. **导入**：侧边栏“实验” → “导入数据…”（⌘O），把仪器导出的 CSV/TXT/XLSX/XLS 拖进窗口（旧版 XLS 每表最多 65,535 个数据行，正好停在这一行数时多半被截断）。可一次导入多个文件；Excel 的每个工作表是一张表格。
2. **核对列映射**：每列给出推荐物理量、单位、置信度与依据。黄色提示的列（如“列名像应变但起始值约为 1”“未说明名义应力还是真实应力”“未给出单位”）必须由你修改或勾选“已确认”。带量纲的列没有单位时不能继续——软件不会猜单位。
   - 可选：“AI 识别列…”会先显示将要发送的内容（表头、文件中写明的单位、默认 5 行样例），确认后才发送。AI 与规则不一致的列一律需要你确认。
   - 可选：“保存为仪器导入规则…”，以后同样表头的文件自动套用。
3. **检查数据**：选择测试类型后点“检查数据”。质量检查只标注问题（缺失值、时间倒退、突变、截断、零点偏移、疑似打滑、无法确定断裂点等），不修改数据。
4. **填写元数据**：带 * 的为该测试类型、该列组合的计算所必需（例如用力和位移计算时需要宽度、厚度、标距）。尺寸以 mm 输入。
5. **创建实验**：原始文件只读归档（SHA-256），然后进入分析页。
6. **计算**：右侧设置模量拟合区间（如 λ 1–1.05）、断裂点（默认自动检测，可人工指定）、平滑窗口，点“计算”（⌘R）。每次计算都保存为新版本，旧版本不会被覆盖；“比较版本…”查看参数与结果差异。不需要的版本或整个实验可在分析页（或“实验”页）删除：删除前会确认，其他分析仍在使用的结果不能删除。
7. **数据修正（可选）**：分析页右栏“数据修正 → 添加修正…”：零点校正（减去开头若干点均值）、位移按接触点归零（力首次超过阈值处为零点）、线性基线扣除（在指定横坐标区间拟合直线并扣除）、Savitzky–Golay 或滑动平均平滑。对话框显示修正前后曲线；保存后记录算法、参数、操作者与时间。修正只作用于之后的计算（点“按当前参数新建版本”），已有版本不变；“停用”后不再使用但保留记录。分析结果的“溯源”中列出该版本使用的修正。
8. **出图**：“绘图工作室”——
   - 左栏：模板列表（应用到当前面板）、分析结果（拖到任一面板，或点 + 添加到当前面板）、已保存的图、自定义模板。“材料库”对比模板（模量–韧性等）直接用材料数据库中的性能数值作图（每个材料一组，所有记录都绘出，不取平均）。
   - 中间：多面板实时预览；点面板切换编辑对象。
   - 右栏：版面（行列、尺寸 mm、面板标号、添加/删除面板）、坐标轴（标题、单位、对数、范围）、图例（显示、位置、边框）、系列（拖动或箭头排序、颜色、名称、线/散点、线型、线宽、符号与大小、实心/空心、右轴、误差棒、移除）。
   - “恢复默认”只恢复当前面板的模板样式；“保存为模板”保存版式与样式，可套用到其他数据；“保存配置”保存整张图，下次可恢复；“导出数据与配置”导出图中数据（CSV，完整分辨率）与配置 JSON；导出 PNG（默认 300 dpi，按版面设置）/SVG（文字可编辑）/PDF。默认样式与毕业论文图一致（见 DECISIONS 2026-10-27）。
9. **Origin**：
   - 分析页“导出到 Origin…”：选择模板与格式；Origin 在虚拟机中生成工作簿（原始数据、处理数据、汇总、元数据）与图页（论文图模板），保存 OPJU 并重新打开核验，文件下载到本机。
   - 绘图工作室“导出到 Origin…”：把当前图按面板生成 Origin 图页（论文图模板），曲线、颜色、线型、坐标轴、图例与预览一致；数据以完整分辨率写入工作簿并与图链接，打开工程即可在 Origin 中继续编辑。
10. **报告**：侧边栏“报告”选择分析版本，可下载 HTML/JSON 或打印为 PDF。报告只包含确定性结果，不含 AI 生成的解释。

## 2. 循环拉伸

测试类型选“循环拉伸”，映射拉伸比（或应变/位移）与应力（或力）。循环按拉伸比峰谷自动分割；未闭合的循环会注明“滞后能 ≠ 完整耗散”；残余应变在卸载应力降到设定阈值处读取。

## 3. 纯剪切断裂韧性

1. 分别导入**无裂纹**（测试类型“纯剪切（无预切裂纹）”）与**有裂纹**样品（“纯剪切（有预切裂纹）”），两者同一材料，并填写可拉伸高度 H0、宽度、厚度、预切裂纹长度。
2. 打开有裂纹样品的分析页，选择对应的无裂纹样品，给出 λc：人工输入（照片/视频帧判读，勾选“已确认”）、按同步时间、或力峰值候选（仅参考，结果为临时值，不进入统计）。
3. 选择 λc 定义（裂纹开始增长 / 开始稳态扩展），Gc = H0·W(λc)。λc 超出无裂纹样品断裂前范围时拒绝外推。

## 4. 循环纯剪切疲劳

1. 每个拉伸幅度的无裂纹样品导入为“疲劳：无裂纹样品循环”，计算“稳态能量”得到 G = H0·W（会检查加载功是否已稳定）。
2. 裂纹长度–循环次数数据导入为“疲劳：裂纹长度–循环次数”，填写裂纹位置分辨率；选择对应的稳态结果计算 dc/dN。Δc 小于分辨率时记为“低于检测限”（删失），不记为 0。
3. 在任一裂纹扩展实验中选择“疲劳阈值”，勾选参与的结果并可限定拟合 G 区间：线性外推给出 G0、标准误差与 bootstrap 置信区间；数据不足、斜率非正、明显非线性或 G0 ≤ 0 时拒绝报告。同时给出“未检出最高 G – 检出最低 G”的实验区间——它不代表材料在更多循环下不会疲劳。

## 5. DMA

1. 导入仪器导出的温度扫描数据，测试类型选“动态力学分析（DMA）”，映射温度、储能模量，以及损耗模量和/或 tan δ（可选频率列；多频率数据按频率分组）。模量单位可为 Pa/kPa/MPa/GPa，统一换算。
2. 分析页右侧选择形变模式（拉伸 E′/E″ 或剪切 G′/G″），点“计算”。
3. 结果按定义分别列出 Tg 候选：tan δ 峰、损耗模量峰、储能模量下降起始，并注明频率。出现多个显著峰时不自动选定，请填写“Tg 搜索下限/上限”后重新计算。孤立异常点以空心点标出，不参与 Tg 识别。
4. “多样品比较”勾选其他 DMA 结果：叠加 tan δ 曲线，Tg 按定义、频率与形变模式分组列表，不同组之间不比较。

## 6. 文献与可比性

- 材料数据库页：“文献”筛选查看文献材料；每条数值显示来源（作者、年份、页码、图表号）、提取方式（文献报告值 / 图形数字化估计值）和原文写法。“导入文献记录…”导入 `polymech-literature/1` 格式的 JSON（整份校验，可重复导入）。
- “按条目查看”：每次分析（每个版本）和每条文献记录是一个单独条目；“性能对比图”任选两项性能作横纵轴（可对数），同一条目或同一材料配对，默认只用每个实验的最新版本。
- 每条数值的“可比性…”列出数据库中所有同类数值与它的可比性结论和逐项理由。
- 分析页“文献对标…”：先显示规则检索到的文献记录与可比性；可选地预览发送内容后请求 AI 推荐与解释。AI 只能引用列表中的记录；默认不发送本实验的数值。

## 7. 设置

- 外观：跟随系统 / 浅色 / 深色；减少透明度。
- AI：开关、Provider（默认 Codex CLI）、模型、推理强度（默认由模型决定；越高越慢、消耗越多）；API 方式的 Key 只存钥匙串。关闭 AI 不影响任何计算。
- Origin Bridge：地址、Token（钥匙串）、自动配对、测试连接与诊断信息。虚拟机关闭时其余功能照常使用。

## 8. 快捷键

⌘O 导入 · ⌘R 重新计算（分析页）· ⌘, 设置 · ⌘⌥S 显示/隐藏侧边栏 · Esc 关闭对话框。全部功能可用键盘完成。
