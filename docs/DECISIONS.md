# 决策记录

格式：日期 · 决策 · 依据 · 影响。需求的解释/变更也记录于此（`docs/SPEC.md` 不改动）。

## 2026-10-25 · Bridge 使用 x64 CPython 3.12
- 依据：PyPI `OriginExt 1.2.6` 仅提供 `win32`/`win_amd64` wheel，无 `win_arm64`；Origin64.exe 为 x64（PE 0x8664）。x64 Python 与 Origin 同在 x64 仿真层，COM 进程外调用不跨架构。SPEC 建议 3.11；选 3.12 因 OriginExt 提供 cp312 wheel，且与 Mac 端开发版本一致（“3.11 或兼容版本”）。
- 影响：Bridge venv 位于 VM `%LOCALAPPDATA%\PolyMechBridge`，由 `bridge/windows-origin/setup_env.ps1` 复现。

## 2026-10-25 · VM 运维通道
- 部署/诊断使用 `prlctl exec`（SYSTEM，session 0，用户桌面无窗口）；需要用户交互会话时，由 SYSTEM 注册一次性计划任务（LogonType Interactive）运行 `pythonw.exe` + `CREATE_NO_WINDOW`（`scripts/vm/run_user.sh`）。不开启 Host Shared Folders，不依赖共享目录传文件。
- 变更（同日）：最初使用 `prlctl exec --current-user`，但它会在用户桌面留下 Windows Terminal 窗口，用户要求避免，已弃用。
- 依据：SPEC §6.3 不得无条件依赖某种 CLI 功能——因此这些仅作开发运维工具；产品运行时的 Mac↔Bridge 通信使用 HTTP。

## 2026-10-25 · 只管理自建 Origin 实例
- Bridge 以“启动前后 PID 差集”识别自建实例，始终显式 `op.exit()`；从不使用 `ApplicationSI`/attach 到用户正在使用的实例。
- 依据：SPEC §6.8 安全要求；实测 originpro 外部模式 `atexit` 只 Detach 会遗留进程。

## 2026-10-25 · Mac 端 Python 3.12
- 依据：numpy 2.5 / scipy 1.18 / pint 0.26 均要求 ≥ 3.12；SPEC “3.11 或兼容版本”。与 Bridge 端版本一致。

## 2026-10-25 · 计算引擎接口约定
- `polymech_mechanics` 函数输入/输出均为 SI 数组 + 不可变 dataclass；字段名带单位后缀（`_pa`、`_m`、`_j_m3`、`_j_m2`）。Pint 仅在导入边界（`units.to_si`）做换算与量纲校验，物理量相乘处（Gc、G）额外用 Pint 做量纲断言。
- 结果附 `flags`（code + 中文信息 + severity），不静默修正数据。
- 依赖方向由 `tests/test_architecture.py` 强制。

## 2026-10-25 · 断裂点、循环分割与阈值判据（本项目约定，非论文给出）
- 断裂点：最大应力之后，最后一个“在 5 个采样点内跌破 50%、且之后不再超过该值”的峰；可由用户指定断裂拉伸比覆盖。检测不到时取末点并告警。
- 循环分割：拉伸比峰/谷（显著度 ≥ 总范围 5%）；末端上升视为未完成循环，末端下降视为卸载谷。
- 闭合判据：终点 λ 与起点相差 ≤ 0.01 且应力回到峰值 2% 以内；未闭合时 W_hys 照常计算但注明不等于完整耗散。
- 疲劳阈值线性外推的拒绝条件：可测点 < 3、斜率 ≤ 0、R² < 0.9、二次项 F 检验 p < 0.05、G0 ≤ 0。置信区间为固定种子（默认 0）的成对 bootstrap 2000 次百分位区间。
- 纯剪切 Rp/H0 告警阈值 0.5（见 SCIENTIFIC_METHODS §3）。

## 2026-10-26 · DMA 判据（本项目约定，非论文给出）
- 峰显著度 ≥ 曲线范围 10%；次峰 ≥ 主峰 50% 判为多峰（不自动选定）；E′ 起始需下降 ≥ 0.3 个数量级；tan δ 与 E″/E′ 偏差告警 5%；异常点稳健 z > 6；频率分组相对容差 1%；等温判定温度跨度 < 2 K。全部可在参数中调整并随结果记录。
- 绘图模板在 SPEC §5.2 的 14 个之外增加 3 个 DMA 模板（E″–T、tan δ–T、E′–f），对应 SPEC §4.5 要求的三条曲线与频率扫描。

## 2026-10-26 · 可比性与文献对标
- 可比性规则与阈值见 `docs/SCIENTIFIC_METHODS.md` §7（本项目约定）。结论取最差一项；“信息不足”排在“有条件”之后、“不建议”之前。
- 文献记录以“引用身份”（来源、材料、指标、页码、图表号、原文写法）识别；重复导入时内容有更正则原地更新，避免重复记录。数据文件中为可比性补充了机器可读条件代码（`method`、`lambda_c_definition`、`stress_basis`、`steady_state_cycles`），原文表述保留在 `*_note` 字段。
- AI 文献对标：候选记录由数据库检索，Schema 把 `record_id` 限定为候选集合；返回后再校验材料名与引用记录一致，检测文字中带单位的数值；界面上的数值与来源一律按 `record_id` 从数据库取。默认不发送本实验的材料名、样品名与性能数值，用户勾选后才发送数值。
